# LG-019 — Local names and results

Phase 7 · On-device memory
Depends on: LG-018
Blocks: —

## Outcome

The last player names and count are prefilled on the setup screen. Each finished classic game appends a local result: who played, who lost, when. Home or a simple list can show the recent results. No account.

## Acceptance

- Relaunch prefills the last names.
- Finishing a game adds one result. Rematch adds another when that game finishes.
- Clearing local data from the system removes names and results.

## Out of scope

- Leaderboards, cloud sync, win-rate used for matchmaking.
