# LG-006 — Choosing an end

Phase 1 · Classic rules
Depends on: LG-005
Blocks: LG-008, LG-010

## Outcome

Decision P1. When the player taps a target that only one end can reach, that end is implied. When both ends can reach it, the growth is incomplete until an end is supplied. The rules package exposes that ambiguity instead of silently preferring the head.

The prototype's "head always wins the shared dot" behavior is not replicated.

## Acceptance

- A target reachable from one end applies with that end.
- A target reachable from both ends is rejected by the single-target apply, and accepted once the end is passed.
- Tests place head and tail so they share a neighbor and assert both outcomes.

## Out of scope

- The on-screen second tap. LG-010 draws that. This ticket is the rule.
