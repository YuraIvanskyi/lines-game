# LG-014 — Classic as a mode

Phase 4 · Mode seam
Depends on: LG-008, LG-012
Blocks: LG-016

## Outcome

Classic is data: id, display name, size 8×8, wall chance 0.05, and the current rule set. The rules package deals from a mode. Home starts `classic` by id. The setup screen can show the mode name. No other mode is selectable.

Hardcoded 8 and 0.05 inside widgets are removed in favor of the mode record.

## Acceptance

- Changing the mode record's size in a test deals a grid of that size. The shipping record stays 8×8.
- Home's Play path passes the classic id into the deal.
- The match log from LG-007 stores that mode id.

## Out of scope

- A second mode, a mode shop, rule plugins beyond the fields classic needs.
