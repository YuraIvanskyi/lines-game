# LG-008 — Classic parity tests

Phase 1 · Classic rules
Depends on: LG-004, LG-005, LG-006, LG-007
Blocks: LG-009, LG-014

## Outcome

One test file pins classic mode to the prototype rules worth keeping, and to the proposed corrections in [decisions.md](../decisions.md). Phase 1 is done when this file passes with the rest of the rules tests. The tests assert match values from [port-patterns.md](../port-patterns.md), not a class-for-class stand-in of the Pygame model.

## Acceptance

The file covers at least:

- 8×8, wall chance 0.05, anchor never a wall, same seed, same board.
- King-move only, no wrap off the edge.
- The crossing setup from the prototype reading: a segment between the opposite corners removes that diagonal, and does not remove orthogonal steps.
- Opening growth splits head and tail, anchor remains tail.
- Shared neighbor does not apply until an end is chosen.
- Terminal result names the player who has no growth.
- Replay rebuilds that terminal match.

## Out of scope

- Visual parity with `idea/frames/`. Those frames are 4×4 and use the old skins.
