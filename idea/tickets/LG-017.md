# LG-017 — Android classic loop

Phase 6 · Android
Depends on: LG-016
Blocks: —

## Outcome

The Android build plays the same classic hot-seat flow: home, two-tap start, grow, ambiguous end, pass cue, loss, rematch. Shell differences (system back, gesture inset, haptics) are handled in the Android shell. Rules stay in `packages/rules`.

## Acceptance

- A full 2-player game can be finished on an Android emulator or device.
- System back from the table asks or returns home without corrupting the in-memory match. From home, back leaves the app.
- A rules bug found on Android is fixed in the package and covered by a Dart test.

## Out of scope

- Play Store listing, tablets, online.
