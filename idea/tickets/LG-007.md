# LG-007 — Move log replay

Phase 1 · Classic rules
Depends on: LG-005
Blocks: LG-008

## Outcome

A classic match can be reduced to mode id, seed, ordered players, and the list of applied growths (end plus target). Replaying that record from a fresh deal yields the same ends, the same segments, the same player to move, and the same terminal result.

This record is the future online protocol. No I/O.

## Acceptance

- Replay of a scripted game matches the live match after each move, including a game that has already ended.
- A tampered growth in the log fails at that step and does not produce a match.
- The record round-trips through a plain JSON map.

## Shape

[port-patterns.md](../port-patterns.md). The saved record is mode, seed, players, and moves. Bit grids and segment-key sets are rebuilt by replay. They are not the file format.

## Out of scope

- Files, cloud, versioning beyond a single `logVersion` field set to 1.
