Read in this order:

1. [prototype-understanding.md](prototype-understanding.md) — what the draft actually does.
2. [port-patterns.md](port-patterns.md) — what not to copy from that draft, and the shapes to use instead.
3. [tech-proposal.md](tech-proposal.md) — the recommended stack. Accepting it opens Phase 0.
4. [decisions.md](decisions.md) — locked product choices and the few prototype behaviors still waiting on a yes.
5. [plan.md](plan.md) — phases and exit gates.
6. [ios-device.md](ios-device.md) — the owner's iPhone closes every iOS check a finger can feel.
7. [art-direction.md](art-direction.md) — default Ink theme tokens.
8. [tickets/BOARD.md](tickets/BOARD.md) — what to pick up next. Specs live in [tickets/](tickets/).

A fuller classic-mode note, when it exists, should be `idea/classic-mode.md`. If it disagrees with [decisions.md](decisions.md), that note wins and the decision row is updated in the same change.
